# HR Platform Backend

Бэкенд для приложения "HR Platform" (Rest API)

# Стек технологий

- Java 21
- Spring Boot 4.1.1
- PostgreSQL 18.3
- Flyway 12.4.0
- Swagger (Open API) 3.1.0

### Swagger (Open API)

Чтобы посмотреть документацию Open API, необходимо перейти по адресу 
`http://localhost:8080/swagger-ui.html`
